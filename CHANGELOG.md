# Changelog

## ru-v1

- Обновлены интерпретации результатов по формулировкам Monique; текст дополнительно закреплен в коде приложения, чтобы не зависеть от кэша CSV.
- Возвращен отдельный сбор контактной информации для будущих исследований; человеческая демография по-прежнему не собирается.
- Создана отдельная русскоязычная версия приложения.
- Переведены пользовательские тексты, вопросы, варианты ответов и демографические модули.
- Добавлены настройки Supabase-таблицы для русской версии: `dslq_ru_sessions`.
- Добавлен SQL-шаблон `SUPABASE_SCHEMA.sql` для создания таблиц Supabase.
- Добавлены проектные файлы для отдельного GitHub-репозитория.
